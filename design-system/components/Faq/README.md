# Faq

Perguntas frequentes em acordeão nativo (`<details>`/`<summary>`), sem JavaScript.

- Perguntas escritas como o visitante as faria ("Posso sair e voltar a entrar?"), respostas com a informação primeiro e o detalhe depois.
- Cada pergunta tem `id` para poder ser ligada diretamente (`/informacoes#reentrada`).
- A página `/informacoes` publica o mesmo conteúdo como `FAQPage` em JSON-LD, para pesquisa e assistentes de IA.
- Fechadas por defeito, exceto quando a página abre com âncora para uma delas.
- Máximo 6 na página inicial; as restantes ficam em `/informacoes`, agrupadas por tema (Bilhetes, Acesso, No recinto, Cashless, Acessibilidade).

As respostas da pré-visualização são exemplos. O conteúdo real vem da organização.
